## Project Overview

This project aims to classify disaster events into low-impact and high-impact categories using disaster-related characteristics and an Artificial Neural Network (ANN), with a focus on their implications for urban safety and resilience.

## Objective

The main objective of this project is to classify disaster events into low-impact and high-impact categories and evaluate the performance of an Artificial Neural Network (ANN).

The project also explores the potential application of deep learning in disaster management and urban resilience. A Logistic Regression model is used as a baseline for comparison.

## Dataset Description

The dataset used in this project is the EM-DAT disaster database, which contains information on disaster events, their characteristics, and their human impacts.

## Conclusion

In this project, Logistic Regression and an Artificial Neural Network (ANN) were used to classify high-impact disaster events based on selected disaster-related features.

The Logistic Regression model achieved a slightly higher accuracy (0.77), while the ANN achieved a higher recall (0.33) and F1-score (0.40) for the high-impact class. This indicates that the ANN was better at identifying high-impact disaster events, although its overall accuracy was slightly lower.

Overall, the results show that both models can be used for disaster impact classification, with the ANN providing a better balance for identifying high-impact events. However, the ANN still missed many high-impact disaster events, indicating that further improvements are needed.

## Potential Applications in Urban Resilience

Artificial Neural Networks can support the development of data-driven systems for disaster management and urban resilience. Similar classification models could be adapted to identify high-risk urban areas, classify disaster-prone locations, and support risk-based decision-making. With appropriate urban-level data and further validation, these approaches could contribute to more effective disaster preparedness and emergency response.
